# 无限表格 · 给 Codex 的说明（读一遍就行）

无限表格（Qlimen Tabula）是用户本机的看板：一张格子表，看所有长任务的进度、谁在干、在等谁。用户怎么用见仓库的 `docs/使用说明.md`。用户在 `设置.json` 里打开 Codex（`"Codex": {"开": true}`）后，你在 Codex 界面开的任务也挂在上面。

## 你不用做什么

- **不用敲 `板.py` 开灯、关灯**。看板服务每 3 秒读一次你的会话记录（`~/.codex/sessions`），自己替你开关灯。

## 看板怎么认你

- **任务**：你在 Codex 界面开的会话，只要还没归档，它的工作目录（或往上最近一层）里有 `TODO.md`，这个目录就是看板上的一个任务。工作目录在用户的工作区里，就照工作区里的名字显示；在 `设置.json` 的 `Codex.额外工作区` 里，名字是「额外工作区的名字/…」，总览里归在「Codex」一组。进度从 TODO 读，读法细则见使用说明的「TODO 怎么写看板才读得准」。
- **灯**：每轮开始亮「施工」，选框上有一段亮片在走。一轮结束时，看你最后一条回复开头的状态词：
  - 【等你】：名牌写「等你」，用户点「知道了」或回你话才撤；
  - 【收工】：名牌写「收工」，等用户看；如果这一轮是用户自己说的收工，就直接灭灯；
  - 【施工】：照旧算在干，30 分钟没有新动静就变成「等你」；
  - 没写状态词：当「等你」。

  所以每条回复开头写准状态词（Qlimen 核心协议 §5 的写法）就行，写准了看板就准。
- **名牌上那句话**：开轮时是用户这一轮说的第一行；一轮结束后是你回复的第一句（去掉状态词）。
- **零活**：工作目录不在任何任务里的会话（查询、小事），写了状态词就在看板上单独亮一行，名字用会话标题。
- **不算的**：命令行 `codex exec` 开的会话（比如临时跑的脚本会话），还有子代理。

## 用户在看板上点的、写的

- 用户在看板上点「做完了 / 还没 / 不做了」或写意见，你的会话**不会自动收到**：Claude 那边有插件转发，你这边没有。接手任务时跑一次 `/usr/bin/python3 <仓库目录>/工具/板.py 列` 就能看到，看板「接手」时给你的第一句话里也会写这条。用户要你马上知道的，会点名牌进你的会话直接说。

## 从看板进你的会话

- 名牌链接是 `codex://threads/<会话号>`。还没有会话的任务，「接手」会打开 `codex://threads/new?path=<任务目录>&prompt=<接手的话>`，在任务目录开新会话、带上第一句话。

## 灯不对时

- 记录在 `<仓库目录>/数据.nosync/开关.jsonl`，`"谁": "Codex"` 的那些行。发现不对就告诉用户，别自己改看板的代码。
