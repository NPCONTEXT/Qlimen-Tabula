## 要什么

- **macOS**。作者只在一台 macOS 26 上用过；Windows、Linux 没适配。
- **Xcode 命令行工具**：`/usr/bin/python3`（3.9 以上）和 `git` 都靠它。新 Mac 第一次运行 `python3` 或 `git` 会弹框让你装，也可以先跑 `xcode-select --install`；装过 Xcode 或 Homebrew 的一般已经有。看板不装任何第三方包。
- **浏览器**。看板是本机网页，只听 127.0.0.1，别的电脑访问不了。
- 下面这些是可选的：
  - Claude 桌面应用：装上插件，Claude 的会话自动开关灯（见[让 AI 自动开关灯](#让-ai-自动开关灯)）。
  - ChatGPT 桌面应用里的 Codex：看板读她的会话记录替她开关灯。
  - 原生置顶小窗：用上面那套命令行工具里的 `swiftc` 自己编译。
  - node 和 Google Chrome：跑页面测试。
  - ffmpeg：施工区里给视频候选截缩略图。

## 三分钟上手

1. 把仓库放到一个**路径里没有空格**的地方，比如 `~/Documents/Qlimen-Tabula`：

   ```bash
   git clone https://github.com/NPCONTEXT/Qlimen-Tabula.git ~/Documents/Qlimen-Tabula
   ```

2. 双击仓库里的 `打开无限表格.command`。它在本机开一个小服务，再用浏览器打开 http://127.0.0.1:8770/ 。
   - 第一次打开、又没写 `设置.json` 时，它会先准备演示：8 个演示任务、小说和分镜两个施工区、三盏演示灯（Claude 在写、Codex 等你、K31 在跑）。
   - 关掉那个终端窗口，看板就停了（终端问要不要终止进程，点「终止」）。
   - 也可以在终端里跑：`/usr/bin/python3 ~/Documents/Qlimen-Tabula/工具/板.py 服务`，再自己打开网址。
3. 在看板上点一块任务，原地展开它的步骤；黄的那行是等你拍板的，点开写「做完了 / 还没 / 不做了」或写意见。

演示任务的状态是写死在 `示例/演示工作区/` 那几份 TODO 里的；想重来，删掉 `数据.nosync/` 再跑一次 `板.py 演示`。

## 换成你自己的任务

1. 复制一份设置：

   ```bash
   cp ~/Documents/Qlimen-Tabula/设置.example.json ~/Documents/Qlimen-Tabula/设置.json
   ```

2. 把 `设置.json` 里的 `工作区` 改成放你任务的文件夹（例：`"~/Documents/我的任务"`）。看板会扫这个文件夹下面**所有带 `TODO.md` 的目录**，每个目录就是一个任务；`归档`、`备份`、`资料`、`node_modules`、`.nosync` 结尾和点开头的目录会跳过。
3. 核对读到的设置：

   ```bash
   /usr/bin/python3 ~/Documents/Qlimen-Tabula/工具/板.py 设置
   ```

4. 关掉看板的终端窗口，再双击 `打开无限表格.command`。

总览里按工作区下**第一层文件夹**分组（例：`写作/长篇小说` 归「写作」组）；直接放在工作区根下的任务归「其他」。想指定组的顺序，在 `设置.json` 的 `分组` 里按顺序写组名。

## 怎么看

无限表格是**一张格子表、三个镜头**。浏览器里能看第 2、3 层；原生小窗（见后文）还有第 0、1 层。左上角 x − + 就是全部按钮：关窗、缩一层、放一层。

| 层 | 放什么 |
|---|---|
| 第 0 层：名牌层 | 只剩一列名牌：每个要关心的任务一块，写最要紧的状态（施工 > 等你 > 收工 > 待续）。适合放在屏幕角上 |
| 第 1 层：进度条 | 在干的、等你的、收工了你还没看的、还有活能接着做的（待续）、你钉住的：一行一个，标题 · 进度条 · 几/几 · 名牌 |
| 第 2 层：总览 | 所有任务，一个任务一块；在干、等你的排前面；7 天没动的（休眠）、做完的、你收起的放在最底下 |
| 第 3 层：施工区 | 重活的工作台：一章、一镜都是一格，直接在格子里改、挑、验收（见[施工区](#施工区)） |

- **一块 = 一个任务**，名字取它 TODO 第一行的标题。进度条：绿是做完，黄是要你点头的步骤，浅蓝是在做（🔄），灰白是没做，米色是一周没动的待确认。右边写「完成 / 总数」。
- **点一块**：原地往下长出这一段没做完的步骤，下面的块往下让；再点收回。读不出就写「读不出」，看板不猜。
- **选框的颜色 = 谁在负责**：Claude 橙、Codex 绿、K31 蓝，别家灰。任务自己没人负责时是灰框。
- **亮片 = 正在跑**：选框上走着一段亮片就是在干；停了就是不在跑（等你、收工、待续）。
- **名牌只写状态**：施工、等你、收工、待续、跨区（这个会话本来在别的任务，这一轮来这里动了笔），后面带「?」是回复写的状态词和看板看到的对不上。名牌是链接：点了打开在干它的那个会话。
- **零活**：没碰任何任务目录的会话（查询、小事），回复开头写了状态词，就单独亮一行，名字是会话的第一句话。
- **撞格**：两家同时认领了同一格，名牌前面多一块红的「撞格」。
- **底下一行**：施工 N · 等你 N · 收工 N · 跨区 N · 待续 N；鼠标停在一行上，写它在干什么。
- **左上角名称框**：选中格子的名字（比如「MV·V2·画面」）；在聊天里说这个名字，AI 就知道是哪格。

## 怎么操作

只有两种：**点头、写意见**。

- **TODO 的黄格子**：点开右栏，点「做完了 / 还没 / 不做了」或写意见。看板只记下你的话，TODO 由干活的 AI 照着改。装了 Claude 插件的会话，你停手 20 秒后会收到；别家要它自己跑 `板.py 列` 看。
- **知道了**：AI 交付了、在等你看的，看过以后点展开里那行「知道了」，框和名牌才消失。
- **钉住、放下**：天天做的任务在展开里点「钉在第 1 层」；不想在第 1 层看到的点「放下」。
- **手动调格子**（总览里）：按住一块拖过半格就挪，落点有块就换位；拖右下角的把手改大小，拉高过 2 行就常驻展开，拉到 1 格就折起来；拖进最底下那片就收起。位置存在 `数据.nosync/布局.json`，删掉就回到自动排。
- **⌘ 单击标题**：在访达里打开这个任务的文件夹（单击只展开）。
- **接手**：没有会话在干的任务，右栏里有「接手」：在工作区开一个新会话，第一句话写明任务路径。

## 让 AI 自动开关灯

灯 = 谁在干这个任务。三种接法，可以混着用。

### Claude 桌面应用：装插件

```bash
bash ~/Documents/Qlimen-Tabula/工具/装插件.sh        # 先预演，看它要做什么
bash ~/Documents/Qlimen-Tabula/工具/装插件.sh --装   # 真装
```

它把 `插件/ban-listen` 复制到 `~/.claude/skills/ban-listen/`，再写一个 `看板位置.txt` 告诉插件看板在哪。**新开的 Claude Code 会话**才会加载（已经开着的不会）。装好以后：

- 会话第一次在工作区的某个任务里改文件（或自己敲了 `板.py 开工`），这个任务就亮灯；只读 TODO 不改的不算。
- 你一发话就「施工」；一轮结束看回复开头的状态词：【等你】挂等你，【收工】挂收工等你看（你这一轮自己说了收工就直接灭），【施工】要真有后台任务或定时叫醒在跑才算在干。没写状态词的，一轮结束就当等你。
- 弹问答卡片、计划审批、权限弹框时亮等你，你选完切回施工。
- 在别的任务里动了笔，那边亮「跨区」，这一轮结束就关。
- 你在看板上点的、写的，停手 20 秒后发进在干那个任务的会话（会话忙就排队）。
- 会话开始时，原生小窗没开就在后台打开它（编译过小窗才有）。

状态词、TODO 写法来自 [Qlimen](https://github.com/NPCONTEXT/Qlimen) 的核心协议，配着用最顺；不用 Qlimen 也能用，只是状态词要自己约定让 AI 写。

插件靠的是 Claude 桌面应用的模组机制（`~/.claude/skills/<名字>/` 里的 `.claude-plugin/plugin.json` 加 `hooks/`），不是公开承诺的稳定接口，应用更新后可能失效。卸载：删掉 `~/.claude/skills/ban-listen`，新开会话就没了。

### Codex（ChatGPT 桌面应用）：看板读她的记录

在 `设置.json` 里打开：

```json
"Codex": { "开": true, "家": "~/.codex", "额外工作区": {} }
```

看板服务每 3 秒读一次 `~/.codex/sessions`，她在 Codex 界面开的、没归档的会话，工作目录（或往上一层）有 `TODO.md` 的就是一个任务；每轮开始亮施工，结束照她回复开头的状态词开关灯。她的工作目录不在你的工作区里，就把那个文件夹写进 `额外工作区`（例：`{"Codex": "~/codex-projects"}`），总览里归「Codex」组。给她读一遍 [接入/codex-指南.md](../接入/codex-指南.md) 就行，不用她敲命令。你在看板上点的她不会自动收到，接手时让她跑 `板.py 列`。

### 别的 AI：敲命令

让它在每一段开头敲开工、交付时敲等你、做完敲收工：

```bash
/usr/bin/python3 ~/Documents/Qlimen-Tabula/工具/板.py 开工 写作/长篇小说 --谁 某某 --说 "写第 14 章" --预计 20
/usr/bin/python3 ~/Documents/Qlimen-Tabula/工具/板.py 等你 写作/长篇小说 --谁 某某 --说 "第 14 章写完了"
/usr/bin/python3 ~/Documents/Qlimen-Tabula/工具/板.py 收工 写作/长篇小说 --谁 某某
```

- 任务写任务目录（相对工作区）或看板上的名字。
- 开工的灯租期 30 分钟，30 分钟没再开工就显示成等你；同一个任务同一个谁再开一次就是续期。
- 读你在看板上的动作：`板.py 列`。想让它被叫醒，开工前设环境变量 `BAN_SESSION`（会话号）、`BAN_HARNESS`（接入名），看板会把你的动作投进 `数据.nosync/信箱/<会话号>.jsonl`；也可以让它后台挂 `板.py 等`，你停手 5 分钟后它退出、叫醒会话。
- 怎么打开它的会话、开新会话，照 `接入/claude.json` 的格式另写一份 `接入/<接入名>.json`。

### Qlimen 用户：派工的工人自动亮

在 `设置.json` 的 `派工账本` 写 Qlimen 派工脚本的账本（`<Qlimen>/core/data/用量日志.csv`），账本里「运行中」、进程还在的工人，按 `--dir` 对到任务，自动亮灯。

## TODO 怎么写看板才读得准

看板读的是各任务目录里的 `TODO.md`。照 Qlimen 的写法就能读准；用别的写法，读不出就写「读不出」。演示工作区里的 8 份 TODO 是各种写法的例子，`板.py 对标准` 拿它们核对读法。

- **步骤表**：表头带「编号」或「步骤」的表才算步骤表。编号像 1、2.1、D3、30b。表头下面要有分隔行（`---|---`）；漏了也认，只要表头第一格是「编号」或「#」、有「步骤」、下一行直接是编号行。
- **做完、在做、等你**：行里有 ✅、`[x]`、➡（并到别处）、➖（不做了）算做完，最后一格写「不需要了」也算；🔄 算在做；`[需用户]` 没做完、依赖栏里的步骤都做完了，就算等你（只算当前这一段）。`[需用户·可选]` 和开头写「（可选）」的不算等你，显示成灰的。
- **编号前的勾选框**：「[x] 1」「☑ J1」算做完，「[-] 7d」算不做了，「☐ J5」「[ ] 2」算没做。✅ 写在步骤文字里也算整行做完，只做了一半的别放 ✅。
- **没有步骤表的段**：勾选框本身就是步骤（演示里的「网站改版」）。
- **待触发**：`[待触发]` 的步骤要等时间、用量才知道，不算等你、也不算能接着做。
- **当前这一段**：
  - 段标题带「在做 / 做完 / 搁置」的（Qlimen 的写法，例：`## 第二卷（11-06 · 在做）`），在做的段就是当前段，完成数算全文件；
  - 几段都从 1 编号的（一轮一轮写），取日期最新、没做完的那轮，完成数只算这一轮；
  - 都不是的（按阶段写），从最后一段有勾的往后找第一段没做完的，完成数算全文件；
  - 有两个以上一级标题（`# `）的，一个一级标题开一轮；第一个一级标题写成「名字 · 日期 …」的，任务名取「·」前面那截。
- **跳过的段**：标题带「模板、验收、查到、摸底、结论、资源、已定、先读、备选、记录、原话」的段跳过（只看括号前的标题本身）。所以步骤段的标题别用这些字。
- **名字**：取 TODO 第一行标题，括号里的话和「TODO」字样去掉。

## 施工区

重活（一部小说、一支片子）的每一章、每一镜都是表里的一格。你在格子里直接改字、挑候选、点通过；AI 用命令读你改了什么、写回它的修改。

- **建一个**：

  ```bash
  /usr/bin/python3 ~/Documents/Qlimen-Tabula/工具/板.py 区 新建 写作/我的小说 --模板 小说
  ```

  任务目录里多一个 `施工台/`：`区域.json` 写条目叫什么、有哪些字段、横排还是竖排、每个字段占几格，照着改就行；`状态.json` 是存档。模板在 `工具/施工区模板/`：**小说**（竖排，一章一行）、**分镜**（横排，一镜一列，样图、样片两行放候选）。演示工作区里的两个施工区就是这两个模板。
- **AI 用的命令**：`/usr/bin/python3 工具/施工台.py <施工台目录> 命令 …`，常用的：`加 号 段名 字段=值…`（加一条）、`列`（列出你的改动和意见）、`看 号`、`改 号 字段 值`、`说 号 话`（留话给你）、`处理 号…`（处理完你的意见）、`批` → `出` → `交`（一批候选：写好提示词，你点头后出，交上来让你挑；额度写「无」的不用点头）。不带参数跑看全部。
- **格子的状态**：你改了、AI 还没读到 → 灰框「改了」；AI 读表就算接手 → 橙框「施工」；AI 停下，它改过的格子「验收」、没动的「等你」；点名牌 = 知道了。挑选、这一条通过是你拍板，AI 读到就算完。
- **叫醒**：施工区里的改动不自动发；底下一行出「改了 N 格 · 叫醒 Claude」，点了才打包发进在做这个任务的会话。改了 10 分钟没叫醒，底下一行最左边亮红点。
- **怎么走**：普通滚轮上下，Shift + 滚轮或触摸板横划左右，方向键一次一格，按住空白处拖画布。

## 原生置顶小窗（可选）

浏览器里只有总览和施工区；原生小窗多了第 1 层和名牌层，可以置顶放在屏幕角上，菜单栏还有个图标。要自己编译（需要 Xcode 命令行工具）：

```bash
bash ~/Documents/Qlimen-Tabula/工具/编译小窗.sh
```

编好的程序在 `小窗.nosync/无限表格小窗.app`，双击打开。看板服务没开，小窗会在后台自己开一个，退出时关掉。

- 左上角 x 关窗（收到菜单栏）、− 缩一层、+ 放一层；双击标题栏放一层；⌘M 缩一层。
- 菜单栏图标：点一下收起、再点拿出来；右键有「置顶」「收起到菜单栏」「总览」「重开看板服务」「退出小窗」。
- 每次重编后，小窗开的服务第一次读「文稿」等文件夹时，系统会弹框问，点「好」。
- 本机签名（ad-hoc），没有公证：只在你自己的电脑上编、自己用。

## 设置

`设置.json` 放在仓库根目录（照 `设置.example.json` 写）。没有它就全用默认：工作区是仓库自带的演示工作区。

| 项 | 意思 | 默认 |
|---|---|---|
| `工作区` | 看板扫哪个文件夹；`~` 会展开，相对路径按仓库目录算。写绝对路径最稳 | `示例/演示工作区` |
| `分组` | 总览里分组的顺序（组名 = 工作区下第一层文件夹名）；不在里面的归「其他」 | 空：每个第一层文件夹一组，按名字排 |
| `跳过目录` | 这些名字的目录里的 TODO 不当任务，加在默认的后面 | `归档`、`备份`、`资料`、`冷归档`、`历史资料`、`node_modules`、`__pycache__` |
| `派工账本` | Qlimen 派工脚本的账本，工人在跑自动亮灯 | 不读 |
| `Codex.开` | 读不读 Codex 的会话记录 | `false` |
| `Codex.家` | Codex 的数据目录 | `~/.codex` |
| `Codex.额外工作区` | 工作区外面、Codex 的任务所在的文件夹：`{"名字": "路径"}` | 空 |

插件也读同一份 `设置.json` 的 `工作区` 和 `跳过目录`。改了设置要重开看板服务：没开原生小窗的，关掉看板的终端窗口、再双击 `打开无限表格.command`；开着小窗的，跑 `板.py 重开`（小窗几秒内用新代码再起一个）。插件要新开会话。

## 命令一览

都用 `/usr/bin/python3 工具/板.py 命令 …` 跑；不带参数看完整用法。

| 命令 | 做什么 |
|---|---|
| `服务 [端口]` | 开本机服务（默认 8770） |
| `开工 任务 [格子…] [--谁 名字] [--预计 分钟] [--说 一句话]` | 开灯（施工）；带 `--预计` 会报上一段实际用了预计的几倍 |
| `等你 任务 [--说 交付了什么]` | 交付、等你看 |
| `收工 任务` | 真做完了：灭灯 |
| `跑 任务 -- 命令…` | 命令在跑灯就亮，退出就灭 |
| `列` | 列出你在看板上点过、写过的（含各施工区的） |
| `段 任务` | 打印 TODO 的「现在」和在做的段（接手时读） |
| `等 [静默秒] [最长秒]` | 挂后台，你在看板上点头、写意见、停手一会儿后退出（叫醒会话） |
| `读 [任务]` | 打印看板读到的东西 |
| `对账 [任务]` | 每段预计几分钟、实际几分钟、几倍 |
| `区 新建 任务 --模板 小说` / `区 列` | 建施工区 / 列出施工区 |
| `设置` | 打印读到的设置 |
| `演示` | 准备演示工作区（错开修改时间、登记演示施工区、亮演示灯） |
| `对标准` | 拿演示工作区的 8 份 TODO 核对读法 |
| `重开` | 让正在跑的服务退出、换成新代码：开着原生小窗才会自动再起一个；没开小窗的，要自己再双击启动 |
| `codex` | 手动读一遍 Codex 的会话记录 |

## 数据放在哪、回滚、卸载

- 看板自己的数据都在 `数据.nosync/`：`开关.jsonl`（开灯关灯）、`事件.jsonl`（你在看板上的动作）、`布局.json`（手动排的位置）、`信箱/`（投给各会话的动作）、`施工区登记.json`（有哪些施工区）。删掉它就回到一张白纸。
- 看板**不改你的 TODO**：它只读；你点的「做完了」只是记下来，由 AI 去改。施工区的存档在各任务的 `施工台/` 里，每次写之前会在 `施工台/备份/` 留一份。
- 不想用了：关掉服务、删掉仓库；装过插件的再删 `~/.claude/skills/ban-listen`。

## 常见问题

- **8770 端口被占了**：双击启动时如果看板已经开着，只会再开一个浏览器标签；被别的程序占着，会直接提示，不会打开错的页面。换个端口：`板.py 服务 8780`（原生小窗认 8770，要用小窗就先把占端口的程序关掉）。
- **看板上没有我的任务**：先跑 `板.py 设置` 看工作区对不对；任务目录里要有 `TODO.md`，不能在跳过的目录里；7 天没动的在总览最底下的「休眠」里。
- **一下子所有任务都成了休眠**：看板会把「同一两分钟里一起改过的一批 TODO」当成批量整理、不算动静（免得整理文件夹时满屏乱亮）。clone、同步、批量改过之后会这样；任务再动一下就回来，演示工作区跑一次 `板.py 演示`。
- **Claude 会话不亮灯**：插件只对装好以后新开的会话生效；会话改的文件要在 `设置.json` 的工作区里；路径里带空格的话插件认不出命令里的路径。
- **名牌点了打不开会话**：会话号是插件或 `--会话` 记下的；手敲 `开工` 又没带会话号的灯，点了会走「接手」开新会话。
